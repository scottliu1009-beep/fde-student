# 立项四问

1. 客户实际要解决什么业务问题?
2. 现有能力为什么可能适用，还有哪些边界?
3. 下一阶段需要哪些数据、协作与决策条件?
4. 现在应继续、带条件继续，还是暂缓?

## 案例

| 四问 | 回看这次经历 |
| --- | --- |
| 业务问题 | 投手提效可能帮助服装客户的业务，实际改善仍需验证。 |
| 能力与适用性 | 团队有产品与技术经验，业务判断和具体产品仍在探索。 |
| 阶段条件 | 已有实际投手工作，双方愿意参与;所需数据、人员和投入按阶段落实。 |
| 下一阶段 | 继续共创，先直接了解投手工作、核实切入点;再结合新依据决定后续投入。 |

收件人：产品方 FDE 项目组

各位，

我们会员复购率已经连续四个季度下滑。我在行业会上看了几个 AI 的案例，觉得会员运营这块可以试一试。销售同事介绍过你们的标准产品，这次我希望尽快把它用起来，三个月能看到效果，也好向董事会有个交代。

我先说三件事。第一，把复购下滑的问题解决掉，我的判断是会员老化比较明显。第二，我们有 80 万活跃会员，希望助手能帮运营识别哪些人需要重点经营。第三，识别出来之后，最好能直接给小林一些运营建议，别又让她多整理一套表。

上个智能营销项目没做好，我认为供应商没有交付好。这次既然是在成熟产品上做，你们先看看哪些能直接用，哪些还需要我们配合。系统情况找老周，运营找小林，门店找陈姐，涉及预算和合同再让王经理一起看。

你们先给我一个判断：这件事值不值得继续推进，接下来需要查什么、找谁，以及能先验证哪一部分。不要只给一个功能列表，我关心最后怎么见到效果。

### 准备问题清单
1. 复购率下滑是整体下滑，还是结构性下滑？分会员层级、入会时长、品类拆开看，掉得最狠的是哪一块？
2. "会员老化"这个判断，背后是哪些数据？是新客进不来、老客在流失、还是留存会员消费频次在降？
3. 80 万活跃会员里，真正贡献利润的占比多少？是少数高价值会员在走，还是长尾普遍疲软？
4. 您说"三个月见效、向董事会交代"——董事会最认哪个指标：复购率绝对值、GMV、会员利润、还是活跃度？
5. 行业案例里最打动您的是哪个场景？精准触达、流失预警、还是会员分层运营？我们优先对齐这个。
